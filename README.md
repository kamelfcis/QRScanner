# Engaz Admin

Control plane for provisioning QR menu customers from the private [QRScanner](https://github.com/kamelfcis/QRScanner) monorepo.

**Branch:** `engaz-admin`  
**Production:** `https://engazadmin.vercel.app`

This branch is **not** a customer menu UI. Customer apps live on branches `warda`, `aklet-gambary`, `harameen`, and per-customer slug branches created by the provisioner.

See [docs/ENGAZ_ADMIN.md](./docs/ENGAZ_ADMIN.md) for setup, tokens, templates, and deploy steps.
