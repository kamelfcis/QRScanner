# Admin Manual

## Dashboard Overview
- Live KPIs update every 30 seconds
- Click cards to drill down into analytics

## Menu Management
### Categories
- Create/edit/delete categories
- Reorder by drag-and-drop
- Toggle visibility

### Products
- Add products with bilingual names
- Set dining/takeaway prices
- Mark as popular/new/bestseller
- Upload images

### Gallery
- Upload restaurant images
- Add captions
- Reorder

### Offers
- Create promotional offers
- Set discount type (percentage/fixed)
- Set date range

## QR Codes
- Generate QR codes with 5 templates
- Customize colors
- Link to tables
- Download as PNG/SVG/PDF

## Analytics
- Overview: Daily visitors, scans, orders
- Heatmaps: Peak hours, table usage
- Insights: Trending dishes, search terms
- Export: CSV, Excel, PDF

## Reports
- Generate daily/weekly/monthly reports
- Export in multiple formats

## Settings
- Restaurant info (name, contact, social)
- Theme colors
- Opening hours
